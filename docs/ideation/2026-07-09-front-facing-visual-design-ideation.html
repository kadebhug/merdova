Grounding Context

Codebase context. React 19 + Vite SPA. Home scroll: Navbar → Hero → Services → Process → SurveyWizard → Contact. Brand core is midnight #0B1121, gold #C0A062, glass cards, Outfit + League Spartan. Motion stack (Lenis, GSAP, Framer) is already invested. Pain points: flat dark scroll, accent drift (gold/cyan/amber/emerald/neon), thin loading fallback, Navbar omits secondary tools, Services mobile kills the horizontal scrub, secondary routes diverge visually.

Past learnings. None — docs/solutions/ and CONCEPTS.md are absent.

External context. 2025–2026 portfolio patterns favor expressive type, structural motion, one or two signature interactions, editorial section rhythm, and anti-generic composition (avoid centered soft-blob AI templates). Side tools work as exhibits/proof; surveys can become memorable conversion artifacts.

Topic Axes

  • Section rhythm & visual variety across the home scroll

Asymmetric Proof Hero

Hero / first-viewport Confidence 88% Complexity Medium
Description Break the centered headline/CTA stack. Compose the first viewport as an asymmetric proof stage: brand-forward claim on one side, a living “implementation stage” panel on the other (system nodes, inputs → outcomes) that reuses the existing magnetic blobs and SVG underline as visible signature interactions instead of soft wallpaper.
Basis direct: Hero is full-viewport centered with radial blobs and max-width 800 copy (Hero.css); magnetic blob physics and SVG underline already exist in Hero.jsx but read as ambience. external: 2025–2026 portfolio critiques flag centered soft-blob AI heroes as generic; signature interactions win.
Rationale Highest-visibility square inch on the site. Reusing built interactions means the change is compositional, not a net-new motion project — and it immediately answers “what does Merdova actually do?”
Downsides Needs a clear visual metaphor for the proof panel (risk of becoming another abstract diagram). Mobile layout must stay brand-first without crowding the CTA.
2

Editorial Chapter Scroll

Section rhythm Confidence 90% Complexity High
Description Stop treating the home page as one continuous midnight slab of glass cards. Assign each section a chapter role with distinct background treatment, density, and geometry while keeping the gold/glass core: Services as exhibit shelf, Process as unboxed blueprint (lean on the existing scroll connectors), Survey as instrument stage, Contact as quiet close. Fold in Process’s unique structure instead of re-carding it.
Basis direct: Services/Process/Contact share flat var(--bg-color), repeated glass hover overlays, clustered 3rem headings, and similar subtitle recipes; Survey alone uses a gradient. Process already has scroll-linked connectors and per-step colors boxed inside the same card recipe.
Rationale Fixes the “one reusable component five times” feeling without abandoning the brand. Makes each section identifiable from a cropped screenshot.
Downsides Highest design effort of the set; easy to over-decorate. Needs a chapter grammar so future sections don’t invent one-offs again.
3

Named Accent Legend

Typography & color Confidence 92% Complexity Medium
Description Don’t bleach the palette to “gold everywhere.” Formalize a transit-map legend: gold = brand/CTA, blue = technical, emerald = outcomes/success, amber = energy (if kept), with route accents as named spur lines (BusinessFinder neon stays intentional). Retire unused --accent-color ambiguity, kill accidental cyan hover shadows, and decide Playfair as either one deliberate editorial exception or delete the import.
Basis direct: Process already assigns four step colors; global tokens define gold/blue/emerald but accents fragment across amber, cyan, hardcoded neutrals, and BusinessFinder’s parallel --bf-* system; Playfair is imported and unused.
Rationale Color with jobs reads expensive; color without jobs reads accidental. This is leverage for every later page and hover state.
Downsides Requires a disciplined pass across CSS/JSX. Temptation to over-systematize before shipping visible wins.
4

Merdova Exhibit System

Cross-route brand unity Confidence 91% Complexity Medium
Description Theme-park lands, not one skin: add a lightweight brand shell (mark, return/home, document titles, “artifact by Merdova”) plus an Exhibit/Labs rail on home that surfaces Courses, BusinessFinder, Resume, Sanaflower as proof objects. Keep each route’s personality; make the parent brand legible and discoverable.
Basis direct: Navbar only on home with in-page anchors; no links to secondary routes from nav/hero; BusinessFinder/Resume/Sanaflower diverge in fonts/tokens/titles while Courses already nearly matches home tokens.
Rationale Turns buried work into credibility. Solves discoverability and brand orphaning in one system instead of redesigning every route.
Downsides Some routes may be intentionally private (PIN-gated Sanaflower) — the rail needs curation, not a dump of every URL.
5

Mobile Services Reel

Motion / interaction Confidence 89% Complexity Medium
Description Desktop Services is the signature scrub; mobile currently nukes it (transform: none !important, vertical stack). Ship a mobile-native reel: snap swipe, gold progress rail, peek of the next card — preserve “this section is special,” not the desktop mechanic.
Basis direct: Services uses a 340vh sticky horizontal GSAP scrub on desktop; mobile CSS collapses height/sticky/track and disables transforms. Grounding names this as a signature-interaction gap.
Rationale Many first visits are mobile. A designed fallback is the difference between “polished studio” and “desktop-only demo.”
Downsides Touch UX and reduced-motion need care; don’t recreate a 340vh trap on phones.
6

Branded Loading Ident

Motion / interaction Confidence 93% Complexity Low
Description Replace the plain “Loading…” Suspense fallback with a short studio ident — logo/mark resolving through gold glass, or a micro pulse of the existing Hero blob. Every lazy route already hits this surface.
Basis direct: App.jsx LoadingFallback is centered text only wrapping Home and secondary routes; motion dossier notes no spinner/skeleton/branded animation despite a heavy motion stack elsewhere.
Rationale Highest-frequency, lowest-effort polish. Stops the quality cliff at the exact moment users wait.
Downsides Keep it short; a long branded wait becomes worse than plain text.
7

Survey Review Ceremony

Section rhythm Confidence 78% Complexity Medium
Description Don’t rebuild the whole wizard as a theatrical stage yet. Elevate the review (and success) step into a distinct ceremony: different lighting/density, engagement-brief layout, clearer “this is your solution snapshot” moment before submit — the tailor’s fitting mirror, not another dimmer glass card.
Basis direct: Survey is a rich six-step flow inside one fixed glass card; review items reuse the same glass family with only opacity changes. external: survey-as-conversion-artifact pattern from portfolio research. Verifier: full “ceremony wrapper” was weak; scoped review/success upgrade is sound.
Rationale Last screen before commitment currently under-signals importance. A sharper review moment upgrades conversion feel without rewriting the whole wizard.
Downsides Scope creep toward a full diagnostic product. Keep the first pass visual, not a new data model.
